FAQ

What this first version still needs

Is this already connected to Shopify?

Not yet. The frontend is ready as a premium microsite shell. Next step is wiring it to the Shopify Storefront API or Buy Button/checkout flow once the API access is stabilized.

Can this go live on gripstrengthshop.bomiko.de?

Yes — after DNS for bomiko.de is moved from the parked Hostinger state into an active zone and a subdomain is pointed to Cloudflare Pages or a comparable static host.

Why start with GripStrength?

It is a narrow niche with strong differentiation, high design leverage and a curated-catalog advantage over broad “sports shops”.
