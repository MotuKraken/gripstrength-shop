FAQ

Current blockers and solutions

Is this already connected to Shopify?

Not yet. Phase 2 creates the data/config structure so the page can be wired cleanly once Shopify API access is stabilized. The target collection remains shop:gripstrength.

Can this go live on gripstrengthshop.bomiko.de?

Yes — after DNS for bomiko.de is moved from the parked Hostinger state into an active zone and a subdomain is pointed to Cloudflare Pages or a comparable static host.

What is the current hard blocker?

The frontend is ready. The real blockers are infrastructure, not design: bomiko.de is parked and the Shopify API path still needs a stable access/auth route.
