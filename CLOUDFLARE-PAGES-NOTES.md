# Cloudflare Pages Notes

## Why Cloudflare Pages fits
- static microsite
- free/cheap first deployment
- good match for many niche frontends
- simple custom-domain attach

## What will be needed
- Cloudflare account with DNS control for `bomiko.de`
- Pages project connected to `MotuKraken/gripstrength-shop`
- Custom domain attach for `grip.bomiko.de`

## Current blocker
`bomiko.de` is not yet in an active Cloudflare-controlled zone; it currently resolves to a parked Hostinger page.

## Decision point
Once DNS is moved/connected, this repo is structurally ready for Pages.
